# CRM-systeem
volg de volgende stappen om de CRM op te starten

Installeer WAMP of XAMPP en start Apache + MySQL.

Download het project van GitHub:
CMR-systeem map
SQL database bestand

Plaats de map CMR-systeem in:
WAMP: C:\wamp64\www\
XAMPP: C:\xampp\htdocs\

Open phpMyAdmin via:
http://localhost/phpmyadmin
Maak een nieuwe database aan
Import de meegeleverde .sql file

Controleer eventueel config.php (database instellingen).

Start de server en ga naar:
http://localhost/CMR-systeem
